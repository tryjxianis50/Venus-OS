# Venus OS

Venus OS is a custom Linux distribution based on Debian 13.7, with KDE Plasma 6.8.2 and Linux kernel 7.3.4 as its target desktop and kernel versions.

> **Development status:** This project is under development. Release, installation, and upgrade instructions will be published here when they are ready.

## Project goals

- Build a Debian-based desktop operating system.
- Provide a KDE Plasma desktop experience.
- Maintain Venus OS packages and release information in the companion [APT repository](https://github.com/tryjxianis50/Venus-OS-APT-repository).

## Versions

| Component | Target version |
| --- | --- |
| Base distribution | Debian 13.7 |
| Desktop environment | KDE Plasma 6.8.2 |
| Linux kernel | 7.3.4 |

These are the project targets; availability and support may change during development.

## Getting started

There is no installation image or setup procedure documented here yet. Please do not use this repository as an installation source until an official release and its verification instructions are published.
